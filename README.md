# Dimas Wisnu Firdaus — Portfolio Website

A responsive, static portfolio website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example: `dimas-portfolio`).
2. Upload **all files and folders** from this package. Keep `index.html` at the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will appear in the Pages settings.

For a user/organization site, the repository can instead be named `YOUR-USERNAME.github.io`.

## Update content

- Edit `index.html` to update text, links, and sections.
- Replace `assets/dimas-profile.jpg` to change the profile image.
- Replace `assets/Dimas-Wisnu-Firdaus-Portfolio.pdf` to update the downloadable PDF.
- Gallery photos are stored in `assets/gallery/`; update the matching image files or edit their cards in `index.html`.
- Keep the filenames unchanged unless you also update the paths in `index.html`.

## Notes

- This is a static HTML/CSS/JavaScript site; no backend or build step is required.
- Verify contact details, employment dates, and all achievement figures before publishing publicly.
